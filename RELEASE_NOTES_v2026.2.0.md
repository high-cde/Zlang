# ZLang v2026.2.0 — Sovereign Execution Layer

Questa release presenta ZLang come execution layer nativo per l’ecosistema ZDOS.

## Highlights

- README pubblico completamente riorganizzato e orientato a sviluppatori, maintainer e partner tecnici.
- Whitepaper tecnica e strategica in `ZLANG-WHITEPAPER.md`.
- Architettura documentata per lexer, parser, AST, type checker, bytecode, VM, runtime e syscall ZDOS.
- Modello di sicurezza basato su capability, policy, whitelist e audit.
- Roadmap pubblica in sei fasi, dalla fondazione verificabile alla distribuzione edge e sovrana.
- Riferimenti contestuali ufficiali a SpaceX e Starlink, con dichiarazione esplicita di non affiliazione.
- `one-shot-zlang.sh` per backup e validazione locale senza push automatico.
- `.gitignore` per evitare la pubblicazione di backup e report temporanei.

## Stato

ZLang è un prototipo avanzato con specifica estesa e implementazione in consolidamento. La release privilegia la trasparenza tra funzionalità documentate, componenti prototipali e roadmap futura.
