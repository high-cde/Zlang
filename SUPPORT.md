# Supporto

## Canali corretti

Per domande d'uso, chiarimenti sulla documentazione e proposte non urgenti, aprire una discussione o una issue con il modello appropriato. Prima di segnalare un problema, consultare il README, la documentazione nella directory `docs/` e le issue già aperte.

## Sicurezza

Non pubblicare segreti, token, dati personali, log sensibili o dettagli di vulnerabilità nelle issue pubbliche. Per problemi di sicurezza, seguire la [policy di sicurezza](SECURITY.md), quando disponibile.

## Informazioni utili

Una richiesta di supporto efficace indica versione o commit, ambiente, passaggi riproducibili, comportamento osservato, comportamento atteso e output pertinente già sanificato.
