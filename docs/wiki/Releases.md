# Release e versioni

Le release pubblicano snapshot tracciabili del ramo predefinito. Ogni release deve collegare tag, note di rilascio, changelog e indicazioni di verifica; non deve affermare garanzie di sicurezza o maturità non dimostrate.

| Elemento | Regola |
|---|---|
| Tag | Versione unica e puntata a un commit immutabile. |
| Note | Modifiche, limiti noti e verifiche effettivamente eseguite. |
| Changelog | Aggiornato in [CHANGELOG.md](../../CHANGELOG.md). |
| Verifica | Comandi e risultati pertinenti dichiarati in modo riproducibile. |

Le release sono consultabili nella sezione [Releases](https://github.com/high-cde/Zlang/releases) del repository.
